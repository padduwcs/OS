# PADOS · Hệ điều hành

Bài giảng Hệ điều hành bằng tiếng Việt cho người mới bắt đầu, bám theo *Operating System Concepts*, 10th Edition (Silberschatz, Galvin, Gagne, 2018). Lộ trình gồm 9 buổi; bốn buổi hiện có bao quát Chapter 1–10.

| Buổi | Chương | Nội dung |
| --- | --- | --- |
| [1](https://padduwcs.github.io/OS/buoi-1.html) | Chapter 1–2 | Introduction & Operating-System Structures |
| [2](https://padduwcs.github.io/OS/buoi-2.html) | Chapter 3–5 | Processes, Threads & Concurrency, CPU Scheduling |
| [3](https://padduwcs.github.io/OS/buoi-3.html) | Chapter 6–8 | Synchronization Tools, Synchronization Examples, Deadlocks |
| [4](https://padduwcs.github.io/OS/buoi-4.html) | Chapter 9–10 | Main Memory & Virtual Memory |
| 5 | Chapter 11–12 | Mass-Storage Structure & I/O Systems |
| 6 | Chapter 13–15 | File-System Interface, Implementation & Internals |
| 7 | Chapter 16–17 | Security & Protection |
| 8 | Chapter 18–19 | Virtual Machines, Networks & Distributed Systems |
| 9 | Chapter 20–21 | The Linux System & Windows 10 |

Mỗi buổi đi từ một tình huống cụ thể, đặt vấn đề trước khi đưa ra cơ chế, và giữ tên chương, tên mục cùng thuật ngữ gốc của giáo trình kèm chú thích tiếng Việt. Trang có hình minh họa, mô phỏng từng bước với câu hỏi “Đoán trước”, bài tập tự kiểm tra có lời giải và bảng thuật ngữ Anh–Việt.

Trang dùng HTML, CSS và JavaScript thuần. Để xem bản cục bộ, mở `index.html` trong trình duyệt. GitHub Pages phục vụ các tệp ở thư mục gốc nhánh `main`. Giao diện dựa trên [CSAI](https://github.com/padduwcs/CSAI).

Giáo trình PDF chỉ dùng cục bộ để đối chiếu và không được đưa lên repo (`*.pdf` nằm trong `.gitignore`).
